# Smart Disease Prediction System

This project predicts diseases based on user-provided symptoms using supervised machine learning.

## Features
- Symptom-based disease prediction
- Decision Tree Classifier
- 97% accuracy
- Streamlit web interface

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit

## Dataset
- Symptom-based disease prediction dataset
- Source: Kaggle
- CSV format

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
